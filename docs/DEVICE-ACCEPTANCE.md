# iPhone 验收

目标设备：iPhone 17 Pro Max / iOS 27.0。先从成功的 Actions 运行下载未签名 IPA，核对同批 SHA-256，再自行签名。解压 Artifact 的 ZIP 后才是实际 IPA。

## 安装与账号

- 安装与首次启动；桌面名称正确；分享扩展正常；签名工具为主程序和扩展使用匹配的 Bundle ID 前缀。
- 网页登录后原生列表保持登录；Cookie 登录可用；注销后网页不再残留前一个账号会话。
- E-Hentai / ExHentai 切换按当前账号真实权限访问。
- 切后台再回来时隐私模糊、Face ID 解锁和超时锁定正常。

## 浏览与互动

- 最新、热门、各排行、订阅更新、历史均能打开并分页。
- 中文/日文标题、标签翻译、关键字、命名空间、高级筛选、图片搜索、快速搜索。
- 详情、缩略图、评论、发评/编辑/投票、评分、收藏增删、收藏分类移动。
- 长按列表画廊加入本地收藏；扩展工具能打开详情及子页面；移除后持久化。
- 添加本地屏蔽规则：标题包含匹配，上传者与标签完整匹配；全部隐藏的页面可继续翻页。

## 阅读与下载

- 竖向、左右翻页、缩放、横屏、双页、自动翻页、跳页、预加载、动态图片、保存图片。
- 中途退出、进后台及强制退出后，阅读进度恢复。
- 下载、暂停、恢复、失败重试、移动文件夹、删除、校验和修复；只在 Wi-Fi 下载的限制。
- 飞行模式打开已完成下载，全书翻阅，不应依赖网络获取页列表。
- 从“文件”导入图片目录后，在下载的 Imported 文件夹中离线阅读；原始目录内容不变。
- 系统调度和用户强制退出对后台任务的限制需单独记录，不能用模拟器结果替代。

## 数据与网络

- 导出备份到“文件”；修改设置后恢复；错误、超大或新版本备份应拒绝，不覆盖当前数据。
- 备份不含 Cookie/密码；图片目录独立复制，不混同于 JSON 设置备份。
- 使用自己的可用网络测试 Hosts、加密 DNS 和代理；启用代理后关闭 SNI 直连；关闭代理后恢复系统网络。
- 应用 WebKit 页面与原生请求使用当前账号；站点标签管理、站点设置、账号配额和新闻可操作。

每项记录：IPA SHA-256、设备系统版本、操作步骤、预期、实际、复现频率。构建成功不自动将上述项目标为通过。
